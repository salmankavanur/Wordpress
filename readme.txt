A premium-grade, full-featured Two-Factor Authentication (2FA) plugin for WordPress. Secure your site with TOTP and Backup Codes.

== Description ==

WP 2FA Auth by DigiBayt provides robust security for your WordPress site by adding an extra layer of protection to the login process. Built with modern web technologies and a focus on privacy, it ensures that your user accounts are safe from unauthorized access.

= Key Features =
* **TOTP Support**: Compatible with Google Authenticator, Authy, Microsoft Authenticator, and more.
* **Local QR Generation**: Unlike other plugins, we generate QR codes locally in your browser. No external API calls, ensuring maximum privacy.
* **Backup Codes**: Generate emergency access codes to ensure you never get locked out.
* **Audit Logs**: Comprehensive logging of security events (logins, 2FA activations, failures).
* **Role Enforcement**: Force specific user roles (like Administrators) to use 2FA.
* **Modern Dashboard**: A clean, React-powered interface integrated seamlessly into WordPress.
* **Developer Friendly**: Clean, object-oriented PHP backend and modern TypeScript frontend.

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory, or install via the WordPress 'Add New' plugin screen.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to the 'WP 2FA Auth' menu in your sidebar to configure settings.
4. Users can enable 2FA for their accounts under the 'My Security' tab in the plugin dashboard.
